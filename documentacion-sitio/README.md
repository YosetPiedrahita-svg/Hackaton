# AtmoSmart — Documentación y evidencia (Hackatón UFPS–EISI 2026)

Sitio estático hecho con [Docusaurus](https://docusaurus.io/) que documenta AtmoSmart, proyecto ganador del 1er Puesto.

## Comandos

```bash
npm install     # instalar dependencias
npm start       # desarrollo en http://localhost:3000/Hackaton/
npm run build   # genera /build
npm run serve   # sirve /build en local
```

## Publicación (GitHub Pages)

Se publica con GitHub Actions al hacer push a `main`
([workflow](../.github/workflows/deploy.yml)). Una sola vez, en el repositorio:
**Settings → Pages → Source: GitHub Actions**.

URL final: https://yosetpiedrahita-svg.github.io/Hackaton/
